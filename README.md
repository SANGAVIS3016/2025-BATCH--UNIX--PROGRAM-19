# Linux Crontab Assignment

## Aim

To create and configure a cron job for the current Linux user using the `crontab` command.

## Learning Objectives

After completing this assignment, students should be able to:

- Check the current user's crontab.
- Edit/create a user's crontab.
- Understand the five fields of a cron schedule.
- Add a job to a crontab.
- Execute a shell script through cron.
- View the configured cron jobs.
- Remove or modify cron jobs safely.

---
